# AI 使用过程说明

## 人类提供与决策

用户提供完整原创题材、校园事件、学习目标、17 页初稿、5 道正式题、无伞约束、评分办法、视觉方向及交付要求。核心实验逻辑与叙事链条来自用户。用户授权在自己的 GitHub 账号创建仓库并上传，未授权修改老师仓库。

## AI 辅助范围

1. 审阅逐页稿：压缩重复表述，修正多选与自由回忆的区别，补齐不确定反馈，指出前置教学造成的方法学限制。
2. 提炼统一视觉提示词，通过内置 image_gen 工具分别生成三幅插画。未调用付费 API 密钥或 CLI 回退。
3. 从零实现静态网页、计时封存、评分、记录与本机保存。
4. 生成并执行逻辑与真实浏览器交互测试，目检桌面、手机及揭晓截图，修正浅色纸面上的对比度。
5. 整理 README、设计说明、测试报告和真实试玩模板。

## 视觉产物与核验

最终交付素材：`assets/scene.png`、`assets/corridor.png`、`assets/xiaolin.png`。生成后直接复制到项目，未人工拼接、删除物件或更换揭晓图。原图与揭晓为同一文件。主图的五个要素及无伞约束经视觉目检；仍建议邀请目标玩家检查辨识度。

2026-09-17 更新：用户比较构图并提出完整椅背、倒地书包与散落资料、离开人物更有动感的要求；最终明确选定并上传主图。本次将该附件原样复制为 scene.png，目击与揭晓共用，不再生成或修图。教学提示后移的方案经用户批准后实施。

初版视觉提示词见 `视觉提示词.md`。模式：内置 image_gen。插画不是历史照片、真实学生形象或研究录像。

## 证据与诚信

测试报告中的自动化结果来自实际运行，测试玩家数据为合成数据，不是真实课堂统计。试玩模板保持空白，未虚构参与者、评价、使用时间或心理学实验结果。

代码、文本与绘图辅助均已披露。用户提交作业前应按课程规则说明 AI 使用情况，并自行确认最终内容与引用。AI 不代替真实试玩、教师评阅或正式研究伦理审查。
