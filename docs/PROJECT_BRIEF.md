# 制作简报与文案修订决策

以用户提供的 17 页逐页稿为底稿，保留顺序、人物、五题和核心反转。面向中学生至大学低年级，目标 5—10 分钟。独立 HTML/CSS/JS，无后端、无统计上传，GitHub Pages 可部署。

## 第一阶段：文案审阅
- 每页只推进一个判断。压缩重复换行与解释，完整的针对性反馈保留在各自选项之后。
- 开场及浏览器标题只显示「4:17｜二楼走廊」，完整作品名第 15 页揭晓；不在初始页面提及心理学术语。
- 保留第 3 页多选记录，增加可先填写的自由文本和「其他」；准确称为「自由描述 + 提示选项记录」，不把多选当无提示自由回忆。
- 删除小林页面替玩家断言「你脑子里闪过黑色东西」的句子，改成「你把这句话也记了下来」。不给玩家伪造主观体验。
- Q1 补充录像需核验时间、视角、完整性，不把录像当绝对真相。
- Q3 提示改成「区分谁说过，与什么已被核实」。原稿声称雨伞第一次明确出现在小林处不成立，第 3 页选项已出现。
- 第二次记录保留有 / 好像有 / 好像没有 / 无法确定，并增加「没有，我记得比较清楚」，避免强迫确定的否定回答选择模糊选项。
- 比较分支区分初次选伞、未选后报有、未选后否定、未选后不确定。不把未选择推断成确定没有看见。
- 揭晓重放同一张素材，不伪称刚找到监控；证据范围为这张原始插画。
- Q4 以假设情境出题，不编造真实玩家数据；该现象提示可能性，不能单独确立因果。
- Q5 随机分组，同一素材、时长、间隔、测试，只改变误导描述；正式实验测试前不进行 Q2/Q3 教学。
- 第 14 页说明这次是教学演示，不是受控实验；选择题提示和前置反馈均可能影响回答，错误报告不必等同记忆痕迹被改写。
- 原稿结算示例 4 次独立 + 1 次纠错应为 92 分，而非 86 分。正式分数按真实记录计算。

## 第二阶段：视觉规范
橙金黄昏 #e8ad68、墨蓝阴影 #19282e、黑墨 #111b20、纸白 #f3ead8、灰蓝 #8da4aa。标题用本地宋体衬线，正文系统无衬线；16:9 漫画主画幅、窄边框、旁白纸条。开场长走廊、小林走廊半身像、目击教室三幅统一墨线插画。揭晓复用同一主图；结算用走廊图与调查档案纸面。

## 实施与验证顺序
1. 完成文案和分支数据：可审阅逐页稿。
2. 生成并目检三幅插画：主图不得含任何可合理识别为雨伞的物体。
3. 实现 17 页流程、首次记录、重答与分数、进度恢复、揭晓与反思。
4. 浏览器验证五秒、刷新/返回、计分和移动端；保存测试报告。
5. 整理 README、设计说明、AI 说明、试玩模板及部署包。目标仓库未提供前不修改老师仓库，也不虚构公开链接。
