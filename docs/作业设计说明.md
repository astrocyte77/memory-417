# 作业设计说明

## 核心设计

《记忆里多出来的那把伞》从校园小事件进入，让玩家先当目击者，再当研究者。前九页体验信息如何进入调查，十至十三页检查证据和实验设计，十四页才给出心理学名称，十五页揭晓完整标题，十六页结算，十七页迁移到生活。

目标受众为中学生至大学低年级，预计 5—10 分钟。完成时间需由真实试玩复核，阅读速度从不扣分。五秒限制只作用于目击素材。

## 八个学习目标对应实现

| 目标 | 对应页面与体验 |
|---|---|
| 记忆具有重建性质 | 同图重放、前后记录对照、第14页讲解 |
| 后来信息可能影响回忆 | 小林描述、诱导问法、第二次记录 |
| 问句可能带隐藏前提 | Q2 不直接接受雨伞存在 |
| 确信不等于准确 | 记忆选项区分确信和模糊感，结算强调 |
| 记错不等于撒谎 | Q4 对故意说谎选项的针对性反馈 |
| 不过度推广 | Q4 排除「所有记忆不可信」「人人必然受影响」 |
| 对照与控制变量 | Q5 随机两组，仅改变是否接触误导描述 |
| 内容与来源的区分 | Q3 区分说过与证实，第14页来源监控 |

## 从用户原稿延续的叙事

保留五秒、倒椅、红本、蓝包、黑盖透明水瓶、离开学生、无伞原图、小林描述、17 页顺序与五题答案。没有把体验压缩为普通知识问答。第一次记录、无分数的细节题、第二次记录、证据回看、开放反思都作为完整剧情环节实现。

删去替玩家断言「脑中闪过黑色」的旁白，避免强加心理体验。自由文本先于提示选项封存；并非把多选伪称无提示回忆。第二次增加确定否定选项，保留「无法确定」。首次没有选伞只能称「未选择」，不能自动视为确定未见。自由文本在揭晓可展开核对。

## 方法学边界

本作是教学演示，不是能推断因果的受控实验。首次多选已含雨伞；Q2、Q3 在第二次记录之前给出来源与前提教学，可能降低、改变或以其他方式影响后续报告。不能把玩家是否「中招」作为作品成败标准。

单次前后变化可能来自猜测、注意、提问方式、顺从或来源归因等，不能直接证明记忆痕迹被覆盖。不编造参与者统计，不给个人贴标签。初次就选伞、不确定、始终否定的人都有合理反馈。

真正研究应预先规定指标（例如最后报告原图有伞的比例），随机分配参加者，两组看同一素材同样时长、使用相同间隔和测试，仅操纵后续描述；在最终测验之前不提供本作的教学反馈。还需要足够样本与不确定性分析、适当的研究伦理安排和事后解释。本章仅教会这些比较原则，不自动收集真实研究数据。

## 视觉与证据

采用黄昏校园墨线漫画：橙金阳光、墨蓝阴影、半开门、长走廊、日常环境的轻微悬疑感。三幅完整 PNG 保持统一调性；没有恐怖或犯罪暗示。原图与揭晓调用同一素材 `assets/scene.png`，不是两幅近似图。离开学生双手没有持物。重点物件以点击后的覆盖框定位，原始像素不改变。

主图人工目检：倒椅、红本、蓝包、透明黑盖水瓶、离开学生齐全，未发现雨伞、伞架或游离长杆。此项依赖人工视觉审核，不声称自动证明所有人都不会产生歧义。

## 评分

五题各 100 / 60 / 30 分。看提示后即进入 30 分档，即使曾经答错，也不再按 60 分。答对之后不再改变分数或提示状态。总分为五题平均数四舍五入。保留每题首答与尝试次数，三类统计互斥。

自由描述、细节题、前后雨伞判断、反思均不计分。不会因没受影响或阅读慢扣分。

## 技术与隐私

静态 HTML/CSS/JavaScript，无服务器、外部字体或运行期第三方依赖。存档键 `memory417.chapter.v1`，不影响老师其他关卡。仅渲染当前页，初始文档标题不剧透。不通过浏览器历史编码页号；目击开始前持久化已开始标记，刷新和后台切换会封存。

无后端可保证普通返回无法回看，但不能阻止查看源代码、直接打开图片、清空存储、截图或主动修改浏览器数据。此边界在教学环境合理，不能作为防作弊安全系统。重玩明确标记，不能再当首次体验。

支持手机布局、键盘选项、焦点提示、减少动画偏好。视觉目击任务本身不等价于屏幕阅读器可访问实验；不应将视觉障碍使用者的结果纳入同一解释。完全无声仍可通关。
