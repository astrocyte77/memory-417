# 4:17｜记忆里多出来的那把伞

一次关于记忆、暗示与证据的调查。原创校园悬疑漫画互动章节，17 幕、5 道正式判断，目标体验时长 5—10 分钟。

> 玩家请直接打开游戏。下面的设计与文案文档包含剧情揭晓。

## 运行

解压完整目录，双击 `index.html` 即可；保留 `assets/`、CSS 与 JS 文件的相对位置。无需后端、账号、构建或外部 CDN。

也可以在项目目录执行：

```sh
python -m http.server 4173
```

打开 `http://localhost:4173`。进度保存在当前浏览器、当前来源；本地文件、localhost 和正式网址不共享存档。浏览器禁用存储时会提示，请在结尾下载记录。

## 功能

- 图片完成解码后，原始教室画面显示 5 秒；随后封存。刷新、离开页面、恢复历史不会重置观看机会。
- 最初自由描述先保存，再显示多选提示。两份记录和非计分细节题独立保存。
- 每题保留第一次答案、全部尝试、是否使用提示。错误选项有独立反馈，答对才能继续。
- 首次独立答对 100，纠错后 60，提示后 30；五题等权平均并四舍五入。提示优先级高于纠错。
- 揭晓重放同一张主图，可定位五条视觉证据。按前后记录生成四类反馈，不把「不确定」算作否定。
- 完整标题与术语延后出现；成绩只衡量推理判断，不评价记忆能力。
- 本机反思保存、JSON 记录下载、章节级重新开始、响应式排版与键盘操作。
- 没有埋点、后台、排行榜或自动上传。导出的自由文本请自行检查后分享。

## GitHub Pages 部署

1. 将本目录的内容放到仓库根目录。
2. 仓库 Settings → Pages → Deploy from a branch。
3. 选择 `main` 与 `/(root)`，保存，等待 Pages 发布完成。
4. 以 Pages 显示的正式地址验证开场和图片。不需要 Actions 配置。

`.nojekyll` 随包提供。全部资源采用相对路径，支持项目子路径。回滚可以恢复上一次提交；只改文字与样式无需修改存档键。未来变更数据结构需要同步调整版本与迁移策略。

## 复跑测试

纯逻辑：`node tests/core.test.cjs`。

浏览器测试先启动本地服务器，再安装测试依赖（仅测试需要）：

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.test.cjs
```

已有 Edge 时可设置 `TEST_CHANNEL=msedge`。可用 `TEST_URL` 指向其他预览站点。浏览器脚本会创建测试存档，仅在自己的隔离上下文内操作。
